## Deployed Cloud Architecture

- **Cloud Run Deployment:** Fully operational on GCP project `my-agentic-ml` (`asia-south1`). Secret Manager provisions live Gemini API and Langfuse credentials.
- **Compute & Cost Model:** Container provisioned at 2 vCPU and 4 GiB memory ($0.000044/sec compute rate). An average 39-second pipeline run consumes ~$0.00172 in Cloud Run compute plus ~$0.00018 in Gemini tokens (total ~$0.0019 per autonomous run).
- **LLM Decisions:** Gemini (`gemini/gemini-3.5-flash-lite`) serves as the sole primary LLM with structured JSON outputs and typed fallback safeguards.
- **A2A Boundary:** The Model-Selection agent operates behind Google ADK's A2A server; the orchestration agents run inside CrewAI.
